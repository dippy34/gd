# Revision history and selection

This is a concise reconstruction from saved files and owner feedback. Historical
assistant notes are preserved as records, not unquestionable quality assessments.
The machine-readable export list is [artifacts.json](../catalog/artifacts.json).

## Project 1: OBSIDIAN-CHOIR / v8

The original request was to create a copy named v8 and work from the layout. Later
requests moved through mixed modes, longer full-song gameplay, corrected song ID
1573528, memory/visibility, size-state fixes, less random clutter, varied rhythm,
random wall decisions and balancing. The owner then switched projects entirely.

Relevant saved revisions include layout, memory, balanced, refined, timing,
clean, branching, nocturne, deception, simple, restored, dark, phrases, rebalance,
sync and variety. Do not assume this naming sequence means each is better or
approved. Notes, validators, reference input traces and backups are retained in
`outputs/` and `work/`. [Gameplay lessons](GAMEPLAY_LESSONS.md) summarize the useful
feedback without converting it into factory requirements.

## Selection made for this repository

The user requested an AI-friendly handoff and told the assistant to ignore the
custom-art part. Factory Orbs is therefore the stable pre-experiment starting
point. The handoff does not silently pick another fire effect or rewrite the
gameplay. Future tasks can revise it based on new feedback.

Root `project-state.json` and `docs/PROJECT_STATE.md` describe this decision.
Historical `CURRENT`, `LATEST`, names and local timestamps cannot override it.
