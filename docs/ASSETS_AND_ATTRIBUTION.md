# Assets, provenance and external references

The source factory metadata credits **ricewithmaggi**. The user supplied the
factory file and the earlier OBSIDIAN-CHOIR handoff. Keep source metadata and
collaborator contributions intact. This repository does not assign a blanket
license to level art, music, game assets or other contributors' work.

## Included

- Source `.gmd` inputs, project exports and local authoring/validation scripts.
- Raw project levels, plans, measurements, revision backups and reports.
- Gameplay/editor screenshots supplied for this task and project previews.
- Research notes, measurements and small object/schema reference data used by
  the tools. The historical object mapping is not a copy of the game atlases.
- Curated documentation derived from owner feedback, without private messages,
  participant names from chat screenshots or unrelated pasted requests.

## Intentionally excluded

- The disregarded CUSTOM-FIRE artwork, scripts, raw level and export.
- Installed Python/vendor dependencies, caches and platform binaries.
- Downloaded music and derived song WAVs; acquire appropriate audio locally.
- Game sprite sheets and raw sprite contact sheets; use your own installation.
- Full downloaded reference levels and their pickled caches.
- Copied third-party binding dump and local binary disassembly; concise research
  findings remain, with their limits.
- Duplicate handoff ZIPs, private chat screenshots, the unrelated Unity paste,
  credentials and OS metadata.

The original excluded files were not deleted from the owner's workspace.
[migration.json](../catalog/migration.json) records paths and reasons for every
workspace-file exclusion. Absolute personal paths in copied text are redacted as
`$HOME` / `$PROJECT_ROOT`; current commands use repository-relative paths or
`GD_RESOURCES`. Binary level exports retain their exact hashes and metadata.
