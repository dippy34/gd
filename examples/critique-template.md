- Source baseline and candidate paths:
- Section/X interval and affected editor layers:
- User request being addressed:
- Retained components and gameplay invariants:
- Before/after images at identical camera, zoom, aspect and trigger time:
- Evidence type: native capture / diagnostic render / editor screenshot:
- Main assembly and industrial function:
- How each added piece attaches; any ambiguous endpoints:
- Hazard/interaction silhouette and negative space:
- Light sources, dark depth, ash and motion:
- Beginning/middle/extreme movement states checked:
- Data regression results:
- Native playtest and performance results (or clearly “not tested”):
- User feedback: pending / retained component / rejected / approved scope:
- Next narrowly scoped change, if any:

Do not fill “user feedback” with the assistant's own opinion. A passing technical
check is not visual approval. Attach the exact candidate so the next review does
not accidentally compare different revisions.
