# Working archive

This directory preserves the authoring history. Its root contains the older v8
gameplay project; `sinking-factory/` contains the later decoration project.
Historical scripts may execute on import or write their named output files.
Use the documented root `tools/` commands for safe inspection and rebuilding.

Historical `CURRENT.md`, `LATEST.md`, success messages and screenshots are
revision-specific evidence. The repository's root `project-state.json` and
`docs/PROJECT_STATE.md` determine the current baseline. Some copied provenance
paths were redacted as `$HOME`/`$PROJECT_ROOT`; they are not executable settings.
Optional music/reference resources and native game assets are not bundled.
