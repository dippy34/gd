# Claude / Opus entrypoint

Read and follow **AGENTS.md**, then **docs/START_HERE.md**.

This is an existing Geometry Dash project, not a request to invent a replacement
level. The owner wants you to learn their taste from explicit feedback and visual
examples. Start at **Factory Orbs / CUSTOM-ORBS**, open the images in
**docs/VISUAL_EXAMPLES.md**, and use **docs/DESIGN_GUIDE.md** as the critique rubric.
Study all six picture categories: bad, good, bad techniques, good techniques,
lessons learned and future improvements. Use numbered callouts to explain a
specific visible feature. **examples/visual-review-questions.md** supplies review
questions; **docs/visual-guide.json** records provenance and structured lessons.
Future diagrams are proposals, not screenshots of finished work or owner approval.

The latest chronological experiment is deliberately not the active baseline.
**Do not resume CUSTOM-FIRE / Factory Wildfire.** Its implementation is excluded
at the owner's request. Other fire-border exports are negative/history examples.

Use **docs/OPUS_PROMPT.md** as a ready-to-use onboarding prompt. For concrete data
examples see **examples/**. Learning here means repository context and iterative
feedback; no model training or fine-tuning has been performed.
