# Export archive

The selected baseline is **The Sinking Factory - CUSTOM-ORBS.gmd** (Factory Orbs).
Root `project-state.json` is authoritative. Other exports are historical; the
v8 files belong to a different project. CLOSING-FIRE and ENGULFED are rejected or
superseded experiments. The disregarded CUSTOM-FIRE export is not included.

Existing notes and validation files describe their associated revision and are
not current approval. Some historical captures are native, while many previews
are atlas diagnostics. Read `docs/VISUAL_EXAMPLES.md` and `docs/HISTORY.md` at the
repository root before selecting a file. All export hashes and statuses are in
`catalog/artifacts.json`.
